# LLM Systems / Inference Infrastructure Engineer

I work on LLM inference systems, with a focus on performance optimization, serving infrastructure, and deployment across diverse hardware environments.

My main areas of interest include LLM inference with **vLLM** and **llama.cpp**, **KV Cache / Prefix Cache**, quantization, and reproducible performance evaluation. I also work on **CUDA / Triton kernel optimization** and inference infrastructure spanning **Kubernetes / K3s, Helm, gateways, observability, and recovery workflows**.

I am particularly interested in understanding where LLM inference systems spend time and resources, identifying bottlenecks through measurement, and improving the system across layers—from inference runtimes and kernels to serving infrastructure.

## Focus Areas

- LLM Inference & Performance Engineering
- vLLM / llama.cpp / Ollama
- KV Cache / Prefix Cache / Speculative Decoding
- Quantization & Reproducible Benchmarking
- CUDA / Triton Kernel Optimization
- Kubernetes / K3s / Helm
- AI Serving Infrastructure & Observability
- ARM64 / Edge AI
